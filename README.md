# Sistema de Gestão de Escalas - Liga da Recreação

Aplicativo web desenvolvido para centralizar e automatizar a montagem de escalas de trabalho, controle de disponibilidades da equipe e fechamento financeiro de recreadores e apoios operacionais.

## Sobre o Aplicativo

O sistema conecta gestores e colaboradores em tempo real. A equipe registra suas disponibilidades mensais e os administradores realizam a escalação por turnos e eventos, com regras claras de prazos, controle de permissões e relatórios automáticos.

## Principais Funcionalidades

- **Central de Notificações e PWA**: Sistema completo de notificações push e alertas internos em tempo real para avisar a equipe sobre publicações de escalas, cancelamentos, prazos de disponibilidade e aberturas extraordinárias. O aplicativo pode ser instalado diretamente no celular ou computador como um app nativo (PWA).

- **Gestão Visual de Escalas**: Calendário interativo para escalação rápida por turnos padrão e apoios específicos (Coordenação, Escritório, Zeladoria e Festas), com identificação visual por cores.

- **Regimes Especiais de Trabalho**: Flexibilidade para configurar horas extras, pernoites e acordos de horário reduzido por colaborador, com botões dedicados de salvar e cancelar para evitar alterações acidentais.

- **Aberturas Extraordinárias**: Liberação de prazos extras de disponibilidade para datas específicas ou modalidades de apoio com travamento automático após o encerramento.

- **Controle Financeiro e Exportação**: Cálculo automático de diárias, adicionais e horas extras conforme o nível hierárquico de cada profissional, com exportação das planilhas mensais para Excel.

## Tecnologias

- React, TypeScript e Vite
- Tailwind CSS
- Firebase (Firestore e Authentication)
- Progressive Web App (PWA) e Push Notifications
